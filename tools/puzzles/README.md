# Puzzle benchmark (human-scale check of the AI levels)

Offline measurement only; nothing here ships with the game. Results and the conversion to a human
Lichess rapid rating are written up in `docs/elo-calibration.md` (section "Human scale").

## Data and attribution

`sample.csv` is a stratified sample of 2661 puzzles from the Lichess puzzle database
(https://database.lichess.org/#puzzles), released by lichess.org under Creative Commons CC0. Puzzles were
generated by Lichess from games played on lichess.org. Columns are the first eight of the original CSV
(`PuzzleId,FEN,Moves,Rating,RatingDeviation,Popularity,NbPlays,Themes`). The full database is never committed.

Rebuild (deterministic; the database changes monthly, so a rebuild picks a slightly different sample):

```sh
curl -LO https://database.lichess.org/lichess_db_puzzle.csv.zst      # into a scratch dir, about 300 MB
zstd -dc lichess_db_puzzle.csv.zst | node tools/puzzles/sample.mjs > tools/puzzles/sample.csv
```

Filter: RD <= 80, popularity >= 80, at least 300 plays; about 120 puzzles per 100-point band from 400 to
2900 (bands below 500 and above 2700 are thin), at most a quarter of a band sharing one motif theme.

## Scripts

- `bench.mjs`: solves every puzzle at each slider level through `ChessAI.eloParams` + `ChessAI.searchWithParams`
  (per-move seed, time cap lifted, so results are reproducible on any machine), the Lichess way: the first move
  is the opponent's, every engine move must match the solution, opponent replies come from the line, any
  mating move counts. Fits the level's puzzle rating (50% point of the Glicko/Elo logistic, scale 400) with a
  bootstrap 90% interval, a free-slope fit, and solve rates per band and per motif.
  `--table cand.json` tests a candidate ELO table; `--engine old.js` benchmarks another `aiPlayer.js`.
- `bench-uci.mjs`: the same scoring for reference engines: Stockfish with `UCI_LimitStrength` (`--sf-elos`, binary
  from `tools/calibration/setup.sh`) and Maia under lc0 at `go nodes 1` (`--maia weights.pb.gz,... --lc0 path`).
  Both are GPL tools used offline only; never commit them.
- `fit.mjs`: the logistic fits.
- `results/*.json`: summaries of the runs quoted in the doc.

```sh
node tools/puzzles/bench.mjs --out tools/puzzles/results/v5b-default.json         # about 8 min on 14 workers
node tools/puzzles/bench.mjs --levels 300,700,1100 --table cand.json --limit 800    # quick check
```
